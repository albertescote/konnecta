# iOS Project - Konnecta

This folder contains the native iOS implementation using **Swift** and **SwiftUI**.

## Setup
1. Open **Xcode**.
2. Go to `File > New > Project`.
3. Select `App` and name it **Konnecta**.
4. Use `com.konnecta.app` as the Organization Identifier.
5. Select `SwiftUI` for the Interface.
6. Once created, replace the generated files with the ones in this folder or move these files into the new project.

## Project Structure
- `KonnectaApp.swift`: Main entry point.
- `ContentView.swift`: Initial view.
- `Info.plist`: App configuration.
